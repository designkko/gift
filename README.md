# 🎉 구글시트 연동 웹 추첨 프로그램

구글시트(Google Sheets)에 **참여자 입력 양식**을 자동으로 생성하고, **상품 및 수량 설정**, **웹 추첨(당첨 시 추첨 대상 자동 제외)**까지 한 번에 처리할 수 있는 프로그램입니다.

---

## 📁 파일 구성

- `Code.gs`: Google Apps Script 백엔드 (구글시트 양식 자동 생성, 참여자/상품 CRUD, 공정 추첨 및 당첨자 제외 처리, 웹 앱/API 제공)
- `index.html`: 웹용 추첨 프론트엔드 (구글시트 내장 실행 + 외부 웹 URL 연동 + GitHub Pages + 로컬 데모 모드 모두 지원)

---

## 🚀 구글시트 연동 및 웹 배포 방법 (약 3분)

1. **새 구글시트 생성**
   - [Google Sheets](https://sheets.new)에서 새 스프레드시트를 만듭니다.
2. **Apps Script 열기**
   - 상단 메뉴에서 **`확장 프로그램` → `Apps Script`**를 클릭합니다.
3. **코드 붙여넣기**
   - 기본 `Code.gs` 파일 내용을 지우고, 이 폴더의 `Code.gs` 내용을 그대로 붙여넣습니다.
   - 왼쪽 파일 목록 옆 **`+` → `HTML`**을 눌러 파일 이름을 정확히 **`Index`** (확장자 제외, `Index.html`로 생성됨)로 만든 뒤, 이 폴더의 `index.html` 내용을 붙여넣습니다.
   - 상단 💾 저장(`Cmd+S`)을 누릅니다.
4. **구글시트 입력 양식 자동 생성**
   - 구글시트 탭으로 돌아와 **새로고침(`F5` / `Cmd+R`)** 하면 상단 메뉴에 **`🎉 추첨 관리`**가 생깁니다.
   - **`🎉 추첨 관리` → `1. 시트 입력 양식 자동 생성`**을 클릭하고 권한을 승인합니다.
   - `참여자`, `상품설정`, `당첨기록` 3개 시트 양식이 자동으로 만들어집니다.
   - (선택) 테스트하려면 **`2. 샘플 데이터 채우기`**를 눌러보세요.
5. **웹 앱으로 배포하기**
   - Apps Script 편집기 우측 상단 **`배포` → `새 배포`** 클릭
   - 유형 선택: **`웹 앱`**
   - 실행 주체: **`나`** / 액세스 권한: **`모든 사용자`** (행사 진행자·참여자 환경에 맞게 선택)
   - **`배포`**를 누르면 나오는 **웹 앱 URL**을 열면 바로 구글시트와 실시간 연동된 웹 추첨 프로그램이 실행됩니다!

> 💡 **팁**: 로컬의 `Index.html`을 브라우저에서 바로 열면 **로컬 데모 모드**로 즉시 UI를 체험할 수 있고, 우측 상단 **`⚙️ 구글시트 연결`** 버튼에 위에서 배포한 웹 앱 URL을 붙여넣으면 로컬 파일에서도 내 구글시트와 실시간 연동됩니다.

## 📊 구글시트 자동 생성 양식 구조

| 시트 이름 | 열 구성 | 설명 |
|---|---|---|
| **참여자** | `이름` \| `전화번호` \| `당첨여부` \| `당첨상품` \| `당첨일시` | `미당첨`인 인원만 추첨 대상에 포함되며, 당첨 시 `당첨`으로 바뀌어 다음 추첨에서 자동 제외됩니다. |
| **상품설정** | `상품명` \| `총수량` \| `당첨수량` \| `남은수량` \| `비고` | `남은수량`은 수식(`=B2-C2`)으로 자동 계산됩니다. |
| **당첨기록** | `당첨일시` \| `상품명` \| `이름` \| `전화번호` | 추첨할 때마다 히스토리가 누적 기록됩니다. |
