# 🎄 2026 내일교회 성탄 선물 추첨 프로그램 사용설명서

구글시트(Google Sheets)와 실시간으로 연동되는 웹 기반 성탄 선물 추첨 프로그램입니다.  
참여자 등록, QR코드 안내지 PDF 출력, 전체화면 카운트다운 추첨, 효과음, 당첨자 자동 제외, 선물 수령 확인, 자동 문자 발송까지 한 번에 운영할 수 있습니다.  
*(구글시트 없이 바로 체험해 볼 수 있는 **로컬 데모 모드(기본 참여자 10명)**도 지원합니다.)*

## 1️⃣ 행사 전 준비하기

### ① 참여자 등록 받기 (QR코드 & 등록 페이지)
1. **태블릿 QR 안내 화면 비치**: 태블릿에 QR코드 안내 페이지(`https://designkko.github.io/gift/qr.html`)를 열어두면 참여자가 스마트폰으로 스캔해 등록할 수 있습니다.
2. **참여자 입력**: 참여자가 QR코드를 스캔해 `register.html`에서 **이름**과 **전화번호**를 입력하면 구글시트 `참여자` 시트에 `등록시간`과 함께 자동 저장됩니다.
   - **중복 규칙**: **이름과 전화번호가 모두 같을 때만** 중복 등록이 차단됩니다. *(가족 등 전화번호가 같아도 이름이 다르면 정상 등록됩니다.)*
3. **QR코드 안내지 출력**: `https://designkko.github.io/gift/qr.html` 에서 **`⬇️ PDF 다운로드`**를 눌러 A4 포스터(`2026_내일교회_성탄선물추첨_QR코드.pdf`)를 저장·인쇄해 행사장에 비치합니다.
4. **관리자 일괄 등록**: 관리자 페이지 **`👥 참여자 입력 & 명단`** 탭에서 단건 입력하거나 **`📋 여러 명 붙여넣기`**로 엑셀/시트 명단을 한 번에 넣을 수도 있습니다.

### ② 상품 및 수량 설정
1. 관리자 페이지 **`🎁 상품관리`** 탭으로 이동합니다.
2. **`+ 상품 행 추가`**로 상품마다 아래 항목을 입력하고 **`💾 설정 저장`**을 누릅니다.
   - **상품명**: 예) `1등 선물`, `크리스마스 롤케익`
   - **총 수량**: 준비된 전체 선물 개수
   - **추첨 인원**: 한 번 추첨할 때 뽑을 인원 수
   - **당첨 수량 / 남은 수량**: 추첨에 따라 자동 계산됨 *(직접 수정 불가)*
   - **비고**: 상품 메모

## 2️⃣ 프로그램 설정 (`⚙️ 설정`)

관리자 페이지 상단의 **`⚙️ 설정`** 버튼을 누르면 한 화면에서 아래 항목을 설정할 수 있습니다.

- **프로그램 타이틀 & 프로그램 설명**: 상단 제목과 안내 문구를 원하는 행사명으로 변경·저장할 수 있습니다. 저장한 타이틀은 참여자 등록 페이지(`{타이틀} 등록`), 당첨 확인 페이지(`{타이틀} 당첨확인`), QR코드 안내지 페이지(`{타이틀} 참여 등록 안내`)에도 자동으로 반영됩니다.
- **효과음**: **`▶`** 버튼으로 미리듣기가 가능합니다.
  - **추첨 카운트다운**: `기본 틱`, `북소리 (드럼)`, `맑은 종소리`, `🎲 랜덤`, `🔇 꺼짐`
  - **당첨 빵빠레**: `웅장한 브라스`, `반짝이는 차임`, `경쾌한 축제`, `🎲 랜덤`, `🔇 꺼짐`
- **구글시트 웹 앱 URL (Apps Script `/exec`)**:
  - 배포한 웹 앱 URL을 입력하고 **`💾 연결 저장`**을 누르면 구글시트와 연동됩니다.
  - **`📱 핸드폰 연결 링크 복사`**로 현재 구글시트 연결 정보가 담긴 관리자 링크를 복사할 수 있습니다.
  - **`🟡 로컬 데모`** 버튼을 누르면 구글시트 연동 없이 브라우저 내 데모 데이터(10명)로 테스트할 수 있습니다.
- **참여자 마감 설정**:
  - **인원 마감**: 설정한 인원(`0` 또는 빈 칸이면 제한 없음)에 도달하면 등록이 자동 마감됩니다.
  - **마감 날짜 / 시간**: 달력에서 날짜를 선택하고 시(`00시~23시`)·분(`00분~55분`)을 선택할 수 있습니다. *(`✕` 버튼으로 날짜를 비우면 시간 제한 없음)*
  - 마감 조건에 도달하면 참여자 등록 페이지(`register.html`)에 **`마감 되었습니다.`** 화면이 표시되며 신규 등록이 차단됩니다.
- **문자 자동발송 API**:
  - **솔라피(Solapi / 쿨SMS)**, **알리고(Aligo)**, **문자천국(skysms)** 중 선택하여 발신번호·API Key(또는 AuthKey)·API Secret/User ID를 설정할 수 있습니다.
  - `추첨 완료 즉시 당첨자에게 자동 문자 발송`을 체크하면 추첨 직후 당첨자에게 1회 자동 발송됩니다.
- **사용설명서 바로가기**: 설정 화면 하단의 **`📖 사용설명서 보기`** 버튼으로 언제든 최신 설명서를 열 수 있습니다.

## 3️⃣ 추첨 진행하기 (무대 / 스크린용)

1. 관리자 페이지 **`🎲 추첨하기`** 탭의 **`1. 상품 선택`**에서 추첨할 상품을 클릭합니다.
   - 해당 상품에 설정해 둔 `추첨 인원`이 자동으로 입력됩니다. *(남은 수량보다 크게 입력해도 남은 수량만큼만 추첨됩니다.)*
2. 개인정보 보호가 필요하면 **`2. 추첨 무대용`** 상단의 **`이름 가운데·전화번호 가리기`**를 켜둡니다. *(예: `김*준`, `010-****-5678`)*
3. 하단의 **`🖥️ 브라우저 전체화면`** 버튼 등으로 브라우저를 전체화면으로 바꾼 후 **`🎲 추첨 준비`** 버튼을 눌러 프로젝터/스크린용 대기 화면을 띄웁니다.
4. **`✨ 추첨 시작!`** 버튼을 누르면 **5 → 4 → 3 → 2 → 1 카운트다운** 후 설정된 빵빠레·폭죽 효과와 함께 당첨자가 발표됩니다.
5. 당첨된 인원은 **`참여자` 시트에서 `당첨`으로 변경되어 다음 추첨 대상에서 자동으로 제외**됩니다.
6. **`닫기`** 버튼 또는 `ESC` 키로 대기 화면을 닫습니다. *(당첨 인원이 많을 때는 가운데 목록만 세로로 스크롤됩니다.)*

## 4️⃣ 선물 수령 확인 & 문자 발송

선물수령처 스태프에게는 **`https://designkko.github.io/gift/winners.html`** 주소를 공유하시면 실수로 `당첨 전체 초기화`를 누를 걱정 없이 안전하게 관리할 수 있습니다.

- **빠른 검색**: 상단 **`전화번호 / 이름 검색`** 입력칸에 전화번호 뒷4자리나 이름을 입력하면 즉시 필터링됩니다.
- **선물 수령 처리**: 각 행의 **`미수령`** 버튼을 누르면 즉시 **`수령`**으로 바뀌며, 상단 **`미수령 N개`** 카운트도 실시간으로 줄어듭니다. *(잘못 눌렀다면 `수령`을 다시 눌러 `미수령`으로 되돌릴 수 있습니다.)*
- **개별 문자 보내기 (`📩 문자`)**: 핸드폰(아이폰·안드로이드)에서 당첨자 옆 **`📩 문자`**를 누르면 기본 문자 앱이 열리며 받는 사람 번호와 당첨 안내 문구가 자동으로 채워집니다.
- **API 일괄/자동 문자 발송**: **`⚙️ 설정`**에서 **솔라피 / 알리고 / 문자천국** API를 연동해 두면 추첨 즉시 자동 발송하거나, `🏆 당첨 기록` 탭에서 미수령 당첨자에게 일괄 발송할 수 있습니다.
- **CSV 엑셀 다운로드**: **`⬇️ CSV 내보내기`**를 누르면 `순서 | 당첨일시 | 상품명 | 이름 | 전화번호 | 선물수령` 열 순서로(`수령` → `미수령` 순 정렬) 파일이 저장됩니다.

## 5️⃣ 당첨 취소 및 초기화 (관리자 전용)

- **특정 인원 당첨 취소**: `👥 참여자 입력 & 명단` 탭에서 해당 당첨자의 **`당첨취소`**를 누르면 다시 `미당첨` 상태로 돌아가고 상품 남은 수량도 1개 복구됩니다.
- **전체 초기화 (리허설 후 본행사 준비)**: `🏆 당첨 기록` 탭의 **`🗑️ 당첨 전체 초기화`**를 누르면 참여자 명단과 상품 총수량은 유지한 채 당첨 상태·기록만 깨끗이 초기화됩니다.

## 6️⃣ 구글시트 구조 & Apps Script 재배포 안내

연결된 구글시트는 다음 3개 시트로 구성됩니다:

| 시트 이름 | 열 구성 |
|---|---|
| **`참여자`** | `등록시간` \| `이름` \| `전화번호` \| `당첨여부` \| `당첨상품` \| `당첨일시` |
| **`상품설정`** | `상품명` \| `총수량` \| `추첨인원` \| `당첨수량` \| `남은수량` \| `비고` |
| **`당첨기록`** | `당첨일시` \| `상품명` \| `이름` \| `전화번호` \| `선물수령` |

### 다른 구글시트에 새로 연결하고 싶을 때
1. 새 구글시트 상단 **`확장 프로그램` → `Apps Script`**에서 [Code.gs](https://raw.githubusercontent.com/designkko/gift/main/Code.gs) 전체를 붙여넣고 저장(`Cmd+S`)합니다.
2. **`배포` → `새 배포`** (`유형: 웹 앱`, `실행 주체: 나`, `액세스 권한: 모든 사용자`)를 선택해 배포하고 나온 `/exec` URL을 복사합니다.
3. 웹 페이지 상단 **`⚙️ 설정`** → **`구글시트 웹 앱 URL`**에 새 URL을 붙여넣고 **`💾 연결 저장`**을 누르면 새 시트로 바로 전환됩니다.
