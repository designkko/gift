# 🎄 2026 내일교회 성탄 선물 추첨 프로그램 사용설명서

구글시트(Google Sheets)와 실시간으로 연동되는 웹 기반 성탄 선물 추첨 프로그램입니다.  
참여자 등록, QR코드 안내지 PDF 출력, 전체화면 카운트다운 추첨, 당첨자 자동 제외, 선물 수령 확인까지 한 번에 운영할 수 있습니다.

## 1️⃣ 행사 전 준비하기

### ① 참여자 등록 받기 (QR코드 & 등록 페이지)
1. **QR코드 안내지 출력**: `https://designkko.github.io/gift/qr.html` 에서 **`⬇️ PDF 다운로드`**를 눌러 A4 포스터(`2026_내일교회_성탄선물추첨_QR코드.pdf`)를 저장·인쇄해 행사장에 비치합니다.
2. **참여자 입력**: 참여자가 QR코드를 스캔해 `register.html`에서 **이름**과 **전화번호**를 입력하면 구글시트 `참여자` 시트에 `등록시간`과 함께 자동 저장됩니다.
   - **중복 규칙**: **이름과 전화번호가 모두 같을 때만** 중복 등록이 차단됩니다. *(가족 등 전화번호가 같아도 이름이 다르면 정상 등록됩니다.)*
3. **관리자 일괄 등록**: 관리자 페이지 **`👥 참여자 입력 & 명단`** 탭에서 단건 입력하거나 **`📋 여러 명 붙여넣기`**로 엑셀/시트 명단을 한 번에 넣을 수도 있습니다.

### ② 상품 및 수량 설정
1. 관리자 페이지 **`🎁 상품 & 수량 설정`** 탭으로 이동합니다.
2. **`+ 상품 행 추가`**로 상품마다 아래 항목을 입력하고 **`💾 설정 저장`**을 누릅니다.
   - **상품명**: 예) `1등 선물`, `크리스마스 롤케익`
   - **총 수량**: 준비된 전체 선물 개수
   - **추첨 인원**: 한 번 추첨할 때 뽑을 인원 수
   - **당첨 수량 / 남은 수량**: 추첨에 따라 자동 계산됨 *(직접 수정 불가)*
   - **비고**: 상품 메모

## 2️⃣ 추첨 진행하기 (무대 / 스크린용)

1. 관리자 페이지 **`🎲 추첨하기`** 탭에서 왼쪽 목록의 **추첨할 상품**을 선택합니다.
   - 해당 상품에 설정해 둔 `추첨 인원`이 자동으로 입력됩니다. *(남은 수량보다 크게 입력해도 남은 수량만큼만 추첨됩니다.)*
2. 개인정보 보호가 필요하면 **`이름 가운데·전화번호 가리기`**를 켜둡니다. *(예: `김*준`, `010-****-5678`)*
3. 상단의 **`🔊 효과음 켜짐 / 🔇 음소거`** 버튼으로 카운트다운·빵빠레 소리를 켜거나 끌 수 있습니다.
4. **`🖥️ 전체 화면`** 버튼을 눌러 프로젝터/스크린용 대기 화면을 띄웁니다.
5. **`✨ 추첨 시작!`** 버튼을 누르면 **5 → 4 → 3 → 2 → 1 카운트다운** 후 빵빠레·폭죽 효과와 함께 당첨자가 발표됩니다.
6. 당첨된 인원은 **`참여자` 시트에서 `당첨`으로 변경되어 다음 추첨 대상에서 자동으로 제외**됩니다.
7. **`확인 (닫기)`** 버튼 또는 `ESC` 키로 대기 화면을 닫습니다. *(당첨 인원이 많을 때는 가운데 목록만 세로로 스크롤됩니다.)*

## 3️⃣ 선물 수령 확인 & 문자 발송

선물수령처 스태프에게는 **`https://designkko.github.io/gift/winners.html`** 주소를 공유하시면 실수로 `당첨 전체 초기화`를 누를 걱정 없이 안전하게 관리할 수 있습니다.

- **빠른 검색**: 상단 **`전화번호 / 이름 검색`** 입력칸에 전화번호 뒷4자리나 이름을 입력하면 즉시 필터링됩니다.
- **선물 수령 처리**: 각 행의 **`미수령`** 버튼을 누르면 즉시 **`수령`**으로 바뀌며, 상단 **`미수령 N개`** 카운트도 실시간으로 줄어듭니다. *(잘못 눌렀다면 `수령`을 다시 눌러 `미수령`으로 되돌릴 수 있습니다.)*
- **개별 문자 보내기 (`📩 문자`)**: 핸드폰(아이폰·안드로이드)에서 당첨자 옆 **`📩 문자`**를 누르면 기본 문자 앱이 열리며 받는 사람 번호와 당첨 안내 문구가 자동으로 채워집니다.
- **자동 문자 발송 (선택 사항)**: 관리자 페이지 상단 **`📲 문자 API 설정`**에서 **솔라피(Solapi/쿨SMS)** 또는 **알리고(Aligo)** API 키와 사전 등록된 발신번호를 입력하고 `추첨 완료 즉시 자동 발송`을 켜두면, 추첨 순간 당첨자에게만 1회 자동 발송됩니다.
- **CSV 엑셀 다운로드**: **`⬇️ CSV 내보내기`**를 누르면 `순서 | 당첨일시 | 상품명 | 이름 | 전화번호 | 선물수령` 열 순서로(`수령` → `미수령` 순 정렬) 파일이 저장됩니다.

## 4️⃣ 당첨 취소 및 초기화 (관리자 전용)

- **특정 인원 당첨 취소**: `👥 참여자 입력 & 명단` 탭에서 해당 당첨자의 **`당첨취소`**를 누르면 다시 `미당첨` 상태로 돌아가고 상품 남은 수량도 1개 복구됩니다.
- **전체 초기화 (리허설 후 본행사 준비)**: `🏆 당첨 기록` 탭의 **`🗑️ 당첨 전체 초기화`**를 누르면 참여자 명단과 상품 총수량은 유지한 채 당첨 상태·기록만 깨끗이 초기화됩니다.

## 5️⃣ 구글시트 구조 & Apps Script 재배포 안내

연결된 구글시트는 다음 3개 시트로 구성됩니다:

| 시트 이름 | 열 구성 |
|---|---|
| **`참여자`** | `등록시간` \| `이름` \| `전화번호` \| `당첨여부` \| `당첨상품` \| `당첨일시` |
| **`상품설정`** | `상품명` \| `총수량` \| `추첨인원` \| `당첨수량` \| `남은수량` (`=B-D`) \| `비고` |
| **`당첨기록`** | `당첨일시` \| `상품명` \| `이름` \| `전화번호` \| `선물수령` |

### 다른 구글시트에 새로 연결하고 싶을 때
1. 새 구글시트 상단 **`확장 프로그램` → `Apps Script`**에서 [Code.gs](https://raw.githubusercontent.com/designkko/gift/main/Code.gs) 전체를 붙여넣고 저장(`Cmd+S`)합니다.
2. **`배포` → `새 배포`** (`유형: 웹 앱`, `실행 주체: 나`, `액세스 권한: 모든 사용자`)를 선택해 배포하고 나온 `/exec` URL을 복사합니다.
3. 웹 페이지 상단 **`⚙️ 구글시트 연결`**에 새 URL을 붙여넣고 저장하면 새 시트로 바로 전환됩니다.
